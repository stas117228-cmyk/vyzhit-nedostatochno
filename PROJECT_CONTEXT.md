# КОНТЕКСТ ПРОЕКТА — Выжить недостаточно

## Что это
Адаптивный авторский лендинг книги **Даниила Сергеева «Выжить недостаточно»**.  
Next.js 14 App Router + TypeScript + CSS Modules. Подготовлен к деплою на Vercel.

## Как запустить локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # production-сервер
```

## Маршруты

| URL | Что |
|-----|-----|
| `/` | Главная (лендинг, 10 видимых разделов) |
| `/thoughts` | Список 4 статей |
| `/thoughts/[slug]` | Полная статья |
| `/read/[slug]` | Режим чтения отрывка |
| `/buy` | Купить книгу (3-шаговая форма) |
| `/gift` | Подарить книгу (5-шагов + живой предпросмотр открытки) |

## Структура проекта

```
vyzhit-nedostatochno/
├── src/
│   ├── app/
│   │   ├── layout.tsx          # Root Layout (шрифты, lang="ru")
│   │   ├── page.tsx            # Главная страница (10 секций)
│   │   ├── buy/                # Купить книгу
│   │   ├── gift/               # Подарить книгу
│   │   ├── read/[slug]/        # Чтение отрывков
│   │   └── thoughts/           # Статьи + /[slug]
│   ├── components/
│   │   ├── Header/             # Навигация (sticky, mobile-menu)
│   │   ├── FormField/          # Универсальные поля форм
│   │   ├── BuyGiftGroup/       # Кнопки «Купить» / «Подарить»
│   │   ├── PhotoPlaceholder/   # Заглушки для фото (заменить на <Image>)
│   │   ├── PrototypeBanner/    # Баннер режима прототипа
│   │   ├── MasterclassForm/    # Форма бизнес-мастерской
│   │   └── SpeakingForm/       # Форма приглашения на выступление
│   ├── data/
│   │   ├── site.ts             # Конфиг: соцсети, цена, режим
│   │   ├── thoughts.ts         # 4 полные статьи
│   │   ├── excerpts.ts         # Отрывки книги
│   │   └── beliefs.ts          # 8 убеждений + 5 отрицаний
│   └── styles/
│       ├── variables.css       # Цвета, шрифты, отступы
│       └── globals.css         # Базовые стили, reset
├── public/
│   └── fonts/                  # СЮДА положить .woff2 файлы
├── .env.local                  # Локальные переменные
├── .env.example                # Шаблон всех переменных
└── README.md                   # Инструкция по запуску
```
