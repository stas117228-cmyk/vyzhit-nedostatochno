# Выжить недостаточно — Авторский лендинг книги

Лендинг книги Даниила Сергеева «Выжить недостаточно».

**Стек:** Next.js 14 (App Router) · TypeScript · CSS Modules  
**Целевая платформа:** Vercel  
**Текущий режим:** Прототип (`NEXT_PUBLIC_SITE_MODE=prototype`)

---

## Быстрый запуск

### Требования

- Node.js ≥ 20.0.0
- npm ≥ 10.0.0

### Локальная разработка

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

### Production-сборка (локальная проверка)

```bash
npm run build
npm run start
```

Проверьте [http://localhost:3000](http://localhost:3000) после старта.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните нужные значения.

| Переменная | Тип | Описание |
|---|---|---|
| `NEXT_PUBLIC_SITE_MODE` | `prototype` / `live` | Режим сайта. По умолчанию `prototype`. |
| `NEXT_PUBLIC_SOCIAL_TELEGRAM` | URL | Ссылка на Telegram |
| `NEXT_PUBLIC_SOCIAL_INSTAGRAM` | URL | Ссылка на Instagram |
| `NEXT_PUBLIC_SOCIAL_YOUTUBE` | URL | Ссылка на YouTube |
| `NEXT_PUBLIC_SOCIAL_VK` | URL | Ссылка на ВКонтакте |
| `NEXT_PUBLIC_BOOK_PRICE` | строка | Стоимость книги (после согласования) |
| `PAYMENT_SECRET_KEY` | секрет | Ключ платёжного сервиса (не NEXT_PUBLIC_) |
| `PAYMENT_WEBHOOK_SECRET` | секрет | Вебхук-секрет (не NEXT_PUBLIC_) |
| `FORMS_WEBHOOK_URL` | URL | Обработчик заявок (не NEXT_PUBLIC_) |

> **Важно:** `PAYMENT_SECRET_KEY`, `PAYMENT_WEBHOOK_SECRET`, `FORMS_WEBHOOK_URL` — **серверные** переменные. Не добавляйте префикс `NEXT_PUBLIC_`, не помещайте в Git.

## Структура маршрутов

| URL | Назначение |
|---|---|
| `/` | Главная страница (лендинг) |
| `/thoughts` | Список статей |
| `/thoughts/[slug]` | Полная статья |
| `/read/[slug]` | Режим чтения отрывка |
| `/buy` | Покупка книги |
| `/gift` | Подарить книгу |

Неизвестные slug возвращают страницу 404.

## Шрифты — временные замены

> **Эти замены должны быть обновлены после получения файлов от заказчика.**

| Назначение | Временный шрифт | Целевой шрифт |
|---|---|---|
| Заголовки | **Oswald** (Google Fonts, кириллица ✓) | Bebas Neue Pro / Bebas Neue Cyrillic |
| Текст, статьи | **Lora** (Google Fonts, кириллица ✓) | Lora (без изменений) |
| Цитата первого экрана | **Lora Italic** | Sign That (при наличии файла с кириллицей) |

Для подключения локальных шрифтов (Bebas, Sign That):
1. Поместите `.woff2`-файлы в `public/fonts/`
2. В `src/app/layout.tsx` замените `Oswald` на `localFont` из `next/font/local`
3. Проверьте отображение строки «Всё происходящее в бизнесе — это отражение тебя самого» и букву «Ё»

## Контент — отсутствующие материалы

| Ключ | Что нужно | Где используется |
|---|---|---|
| `photo01` | Атмосферное фото автора | Первый экран |
| `photo02` | Фото для раздела «Почему появилась книга» | Секция 02 |
| `photo03` | Фото для раздела «Факты» | Секция 03 |
| `photo04` | Фото для раздела «Во что я верю» | Секция 04 |
| `photo05` | Фото для раздела «Во что я НЕ верю» | Секция 05 |
| `photo06` | Фото для раздела «Мышление» | Секция 06 (Три основы) |
| `photo07` | Фото для раздела «Мысли» | Секция 07 |
| `photo08` | Фото для финального призыва | Секция финал |
| `bookCover` | Рендер обложки книги | Мета-изображение |
| `bookSpreadIntro` | Разворот для выдержки | Секция 01 |
| `bookSpreadSales` | Разворот о продажах | Секция 06 — Продажи |
| `bookSpreadPeople` | Разворот об управлении | Секция 06 — Персонал |
| `speakingImage` | Фото для приглашения на выступление | Секция 09 |

**Отрывки книги — ещё не предоставлены:**
- Глава «7 чувств» (продажи) — примерно половина главы
- «Все, что ни случается, все к худшему» (мышление)
- Введение и первая глава (для `/read/intro`)

После добавления фото:
1. Поместите файлы в `public/images/`
2. В компонентах замените `<PhotoPlaceholder>` на `<Image>` из `next/image`
3. Укажите реальные `width`, `height`, `alt` и `priority` для первого экрана

## Развёртывание на Vercel

### Шаг 1: Загрузить в Git

```bash
git init
git add .
git commit -m "initial: landing page prototype"
git remote add origin https://github.com/ваш-аккаунт/vyzhit-nedostatochno.git
git push -u origin main
```

### Шаг 2: Импортировать в Vercel

1. Откройте [vercel.com/new](https://vercel.com/new)
2. Выберите репозиторий `vyzhit-nedostatochno`
3. **Framework Preset:** Next.js (определяется автоматически)
4. **Root Directory:** `.` (корень, если проект в корне репозитория)
5. **Build Command:** `npm run build` (по умолчанию)
6. **Output Directory:** оставить пустым (Next.js управляет сам)

### Шаг 3: Переменные окружения на Vercel

В настройках проекта → **Environment Variables**:

| Переменная | Preview | Production |
|---|---|---|
| `NEXT_PUBLIC_SITE_MODE` | `prototype` | `live` (после готовности) |
| `NEXT_PUBLIC_SOCIAL_*` | — | Реальные URL |
| `PAYMENT_SECRET_KEY` | — | После подключения |
| `FORMS_WEBHOOK_URL` | — | После подключения |

> После изменения переменных, используемых при сборке, требуется новый деплой.

### Шаг 4: Деплой

Нажмите **Deploy**. Vercel автоматически определит Next.js и запустит сборку.

**Успех** = статус **Ready** + рабочий Preview URL.
